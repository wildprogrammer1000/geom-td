# 결로 (GeomTD)

수묵·기하 타워디펜스 프로토타입입니다. 스프라이트 시트나 구매 아트 없이 Canvas 원/다각형/사각형만 사용합니다.

나중에 Capacitor로 iOS/Android 래핑하는 것을 전제로, 정적 파일만으로 동작합니다. 빌드 스텝 없음.

## 실행

    cd /workspace/geom-td
    python3 -m http.server 5180

브라우저에서 http://127.0.0.1:5180 을 엽니다.

## 조작

- 빈 칸 탭/클릭: 단발(청, 30), 광역(호박, 50), 감속(보라, 40) 방사 메뉴
- 타워 탭/클릭: 사거리 표시, 한 번 업그레이드 (데미지/사거리, 골드 소모)
- 다음 웨이브: 적 웨이브 시작 (8웨이브, 마지막은 탱크)
- 일시정지 / 다시 시작
- 마우스와 터치 모두 동작. 390px 폭 모바일 우선.

시작 골드 80, 목숨 20. 처치 시 골드. 목숨 0이면 패배, 8웨이브 클리어면 승리.

## 구성

- index.html — UI, 스타일, 캔버스 셸
- game.js — 맵·전투·이코노미·이펙트·입력
- README.md — 이 문서

의존성 없음. Phaser 없음.

## Capacitor 래핑 (이후)

이 폴더를 웹 루트로 두고 @capacitor/core 와 @capacitor/cli 로 init 한 뒤 ios/android 를 add 하고 cap copy 하면 됩니다. web-dir 은 이 폴더입니다.

사운드는 파일 없이 WebAudio 비프만 씁니다. 스토어·광고·계정 없음.
