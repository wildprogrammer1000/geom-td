# 결로 (GeomTD)

수묵·기하 타워디펜스 프로토타입입니다. Canvas 2D와 타워 스프라이트로 동작합니다.

나중에 Capacitor로 iOS/Android 래핑하는 것을 전제로, 정적 파일만으로 동작합니다. 빌드 스텝 없음.

## 실행

    cd /workspace
    python3 serve.py

브라우저에서 http://127.0.0.1:5180 을 엽니다.

## 흐름

캠페인 맵 → 스테이지 선택 → 전투 → 별 정산 → 맵으로

- **안개 골목** · **성수 다리** · **묵점** 세 스테이지 (경로·시작 골드·적 체력이 조금씩 다름)
- 스테이지 클리어 시 남은 목숨으로 별: 18+ = ★3, 6–17 = ★2, 1–5 = ★1 (localStorage 저장)
- 이전 스테이지 클리어 시 다음 스테이지 해금

## 조작 (전투)

- **BTD6식 배치**: 아래 트레이에서 타워를 탭해 선택 → 빈 칸 탭으로 설치, 또는 트레이에서 드래그해 놓기
- 선택 취소: 같은 타워 다시 탭, 맵 밖 탭, Esc
- 타워 탭: 사거리 표시, 한 번 업그레이드
- 다음 웨이브 / 일시정지(⚙) / 다시
- 모바일 우선 반응형 (폰 → 태블릿 → 데스크톱 사이드바)

시작 목숨 20, 처치 시 골드. 목숨 0이면 패배, 8웨이브 클리어면 승리.

## 상점 (구조만)

캠페인 맵에서 **상점** 진입.

- 광고 제거 · 스타터 팩 — **준비 중** (향후 IAP 자리)
- **광고 보고 골드 +30** — 1초 딜레이 후 다음 전투 시작 골드 보너스 (가짜, SDK 없음)

캠페인 플레이는 무료입니다. 의도된 수익 모델은 광고 제거·코스메틱 등이며, Rush Royale식 타이머/가챠/P2W 상자는 하지 않습니다.
